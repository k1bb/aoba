# AOBA 将来の開発課題・ロードマップ

> **言語 (Language)**: [English (roadmap.md)](roadmap.md) | 日本語

本ドキュメントは、基本結合 Earth System Model 構成（`Glevel-5`・`8 × 1` CRM・`nz = 44`・`ocean_nz = 18`・1850 `piControl`）のフィーチャーフリーズ後における、解像度・並列化・物理過程の将来的な開発課題を整理したものです。

---

## 1. 当面の最優先課題：基本構成の長期スピンアップ・バグ検証・定量評価

新たな物理モジュールの追加は一旦打ち止めとし、現行のフル結合構成の検証と安定化に集中します：
- **多段階平衡スピンアップ（`30 + 1,000 + 70 年`）**：30年結合積分 → 最大1,000年のオフライン 3D SCVT 海洋加速スピンアップ（50年深層ドリフト `< 0.01 K/century` で自動停止）→ 70年結合リスタートを実行する。
- **保存則・物理バグ監査**：大気上端（TOA）放射収支、全球水・塩分収支、海洋熱容量ドリフト、AMOC/ACC 流量、海氷面積、陸海炭素プール、および最適温度順化の多十年挙動を検証する。
- **観測・マルチモデル定量ベンチマーク**：WOA23 海洋気候値、ERA5 大気再解析、および CMIP6 `piControl` アンサンブルに対して平衡気候状態を比較評価する。

---

## 2. 大気・海洋・陸 統一グリッドの解像度目標と海洋鉛直層の高度化

AOBA は大気・海洋・陸で単一の球面重心ボロノイ格子（SCVT）を共有しています。海洋の第一傾圧ロスビー変形半径 $L_d$（赤道 ~200 km、中緯度 20–40 km、高緯度 5–15 km）に照らすと、統一グリッドの解像度ごとの到達水準は以下の通りです：

| Glevel | 全球セル数 | 水平解像度 $\Delta x$ | 海洋／結合モデルとしての格付け | 表現できる現象と残る制約 |
|---|---:|---:|---|---|
| **Glevel-5**（現行基本） | 10,242 | 約 224 km (~2.0°) | 粗格子 OGCM | 大規模風成環流・AMOC/ACC の大枠と全球熱・炭素収支。海峡・赤道潜流（EUC）・西岸境界流の離岸は粗い。 |
| **Glevel-6** | 40,962 | 約 112 km (~1.0°) | 標準 ESM 入口水準 | 標準 CMIP6 ~1° 海洋の水平規模に相当し、海盆規模循環・BGC には十分。赤道細分化がない均一 1° のため ENSO と西岸境界流離岸にはやや甘さが残る。 |
| **Glevel-7** | 163,842 | 約 56 km (~0.5°) | 非渦解像 ESM のスイートスポット | 均一格子のまま **赤道湧昇・EUC・ENSO・主要海峡（インドネシア通過流等）** まで実用解像度に到達。GM 渦パラメタリゼーション併用の気候 ESM として十分な水準。 |
| **Glevel-8** | 655,362 | 約 28 km (~0.25°) | 渦許容（Eddy-Permitting） | 低〜中緯度で中規模渦が自発発生し、黒潮・メキシコ湾流の SST 前線と大気応答が大幅に向上。高緯度は渦グレーゾーン。 |
| **Glevel-9** | 2,621,442 | 約 14 km (~0.125°) | 中緯度 渦解像（Eddy-Resolving） | 黒潮・湾流の離岸、南大洋の渦熱輸送、および季節〜年規模の全球嵐許容（`1 × 1`）実験に対応。 |
| **Glevel-10 / 11** | 1,049万 / 4,194万 | 約 7.0 / 3.5 km | 全球雲解像（`1 × 1` GCRM） | 数週間〜1ヶ月規模の MJO / DYAMOND 級全球雲解像実験および高緯度陸棚・渦解像（マルチノード GPU 領域分割が必須）。 |

### コスト対効果の高い海洋改良：鉛直層数（`ocean_nz`）の増強
- 海洋鉛直層数 `ocean_nz` を現行の `18層` から **`40〜50層`**（表層 0–500 m を高密度化）へ増やすことで、温度躍層（サーモクライン）・赤道潜流（EUC）・海底オーバーフロー・有光層 BGC の再現性が大きく向上する。
- 結合実行時間の 9割以上は大気＋CRM が占めるため、`ocean_nz` を 2〜3倍にしても全体の計算時間増は数%にとどまり、基本スピンアップ検証後の最有力な改良候補となる。

## 3. マルチ GPU 並列化アーキテクチャ

現行実装は 1 GPU（`cuda` / `mps`）動作であり、`Glevel-5`（`8 × 1` CRM）の長期気候計算や独立アンサンブル（`piControl`・古気候・CO₂ 実験の 1 GPU × 複数ジョブ並列）には通信ロスゼロで最適です。一方、`8 × 8` 3D CRM や `Glevel-6/7` 長期気候積分、さらには `1 × 1` 全球雲解像（`Glevel-9`–`11`）へ展開する場合は、以下の 2段階のマルチ GPU 化が有効です：

1. **第1段階 — ノード内カラム並列（NVLink 上の `torch.distributed`）**:
   - 実行時間の約 85〜90% を占めるホスト格子ごとに独立な計算（埋め込み CRM・16バンド CKD 放射・2モーメント雲微物理・MYNN 境界層・陸面/植生タイル）をノード内 4〜8 GPU へ均等分割し、ホスト SCVT 力学へ集約する。
   - 複雑な水平ハロー通信を実装せずに、`Glevel-5` × `8 × 8` 3D CRM や `Glevel-6`–`7` 超パラメータ化気候計算の高速化と VRAM 分散を実現できる。
2. **第2段階 — SCVT 水平領域分割（MPI / NCCL ハロー通信）**:
   - SCVT ボロノイ格子自体を複数ノードへ領域分割し、ホスト力学・FCT 移流・3D OGCM・EVP 海氷に 1-ring / 2-ring ハロー通信を導入する。
   - 単一 GPU の VRAM 上限（40–80 GB）を超え、渦許容・渦解像結合気候（`Glevel-8`–`9`）や `1 × 1` 全球雲解像 MJO / DYAMOND 実験（`Glevel-10`–`11`）の実行を可能にする。

## 4. 今後の検討課題として留保する地球システム拡張

現行フェーズでは実装を見送り、将来必要に応じて検討する拡張項目を以下に記録します：
- **炭素排出駆動モード（`esm-piControl`）**：大気 3D $\mathrm{CO}_2$ 移流と陸海炭素フラックスを完全閉鎖結合し、大気 $\mathrm{CO}_2$ 濃度を処方ではなく予報変数として解くモード。
- **双方向大気化学**：成層圏・対流圏オゾン光化学（$\mathrm{HO}_x/\mathrm{NO}_x/\mathrm{ClO}_x$・PSC）、湿地 $\mathrm{CH}_4$ 放出、土壌 $\mathrm{N}_2\mathrm{O}$、および OH ラジカル寿命フィードバック。
- **陸域窒素・リン循環、深層永久凍土、植生デモグラフィ**：$\mathrm{CO}_2$ 肥沃化の栄養塩制限を表現する土壌無機態 N/P 循環（$\mathrm{NH}_4^+, \mathrm{NO}_3^-$・生物的窒素固定・溶脱）、深層嫌気分解を含む永久凍土炭素・メタン動態、および樹高・年齢クラス競争と油圧枯死を扱う植生デモグラフィ。
- **モーダル・エアロゾル力学と氷晶核（INP）**：粒径モード別の核生成・凝集・内部混合、黒色炭素（BC）の雪氷上沈着によるアルベド低下、および混合相雲の予報 INP 結合。
- **高トップ大気と棚氷–海洋相互作用**：QBO・成層圏突然昇温を対象とした高トップ化（`z_top ~ 80 km`, `70–90` 層）、および棚氷底面融解・氷山カービングの海洋結合。
- **任意の歴史・将来シナリオ外部強制層**：人為起源エアロゾル排出・土地利用変化・火山成層圏エアロゾル・太陽スペクトル変動を、AOBA の普遍物理コアとは独立したプラグイン層として接続する仕組み。
