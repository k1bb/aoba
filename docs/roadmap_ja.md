# AOBA 開発ロードマップ

> **言語 (Language)**: [English (roadmap.md)](roadmap.md) | 日本語

本文書は、基本結合 Earth System Model 構成（`Glevel-5`・`8 × 1` CRM・`nz = 44`・`ocean_nz = 18`・1850 `piControl`）を対象とした長期検証マイルストーン、ならびに今後の解像度拡張・マルチ GPU 並列化・物理過程拡張の設計方針を整理したものである。

---

## 1. 平衡スピンアップおよび定量ベンチマーク検証

基本結合構成における最優先課題は、長期平衡化と観測・他モデル比較による物理的妥当性の検証である。
- **3段階平衡スピンアップ（`30 + 1,000 + 70 年`）**：30年結合積分、最大1,000年のオフライン 3D SCVT 海洋加速スピンアップ（50年深層ドリフト `< 0.01 K/century` で自動収束終了）、および70年結合継続積分を実施する。
- **保存則および物理診断の精査**：大気上端（TOA）放射収支、全球淡水・塩分収支、海洋熱容量ドリフト、AMOC・ACC 流量、海氷面積、陸海炭素プール、および光合成温度順化応答の多十年挙動を検証する。
- **観測・マルチモデル比較評価**：平衡到達後の気候値を WOA23 海洋気候値、ERA5 大気再解析、および CMIP6 `piControl` マルチモデルアンサンブルに対して定量評価する。

## 2. 統一グリッド解像度および海洋鉛直層の高度化

AOBA は大気・海洋・陸面で単一の球面重心ボロノイ格子（SCVT）を共有する。海洋の第一傾圧ロスビー変形半径 $L_d$（赤道域で約 200 km、中緯度で 20–40 km、高緯度で 5–15 km）に対する水平解像度の対応関係は以下の通りである。

| Glevel | 全球セル数 | 水平解像度 $\Delta x$ | 海洋／結合モデルの分類 | 解像される主要現象と残る制約 |
|---|---:|---:|---|---|
| **Glevel-5**（基本設定） | 10,242 | 約 224 km (~2.0°) | 粗格子 OGCM | 大規模風成環流・AMOC/ACC の大域構造と全球熱・炭素収支。狭い海峡・赤道潜流（EUC）・西岸境界流の離岸位置は粗い。 |
| **Glevel-6** | 40,962 | 約 112 km (~1.0°) | 標準 ESM 水準 | 海盆規模循環および海洋 BGC の標準 ~1° 水平規模に相当。赤道細分化を伴わない均一 1° 格子のため、ENSO および西岸境界流離岸の解像度には制約が残る。 |
| **Glevel-7** | 163,842 | 約 56 km (~0.5°) | 非渦解像 ESM の到達目標 | 均一格子のまま赤道湧昇・EUC・ENSO 変動および主要海峡（インドネシア通過流等）を解像し、GM 渦パラメタリゼーション併用の気候 ESM として均衡した構成となる。 |
| **Glevel-8** | 655,362 | 約 28 km (~0.25°) | 渦許容（Eddy-Permitting） | 低〜中緯度で中規模渦が自発発生し、黒潮・メキシコ湾流の SST 前線と大気結合が大幅に改善する。高緯度渦は一部未解像のグレーゾーンに残る。 |
| **Glevel-9** | 2,621,442 | 約 14 km (~0.125°) | 中緯度 渦解像（Eddy-Resolving） | 黒潮・湾流の離岸、南大洋の渦熱輸送、および季節〜年規模の全球嵐許容（`1 × 1`）実験に対応する。 |
| **Glevel-10 / 11** | 1,049万 / 4,194万 | 約 7.0 / 3.5 km | 全球雲解像（`1 × 1` GCRM） | 数週間〜1ヶ月規模の MJO / DYAMOND 級全球雲解像実験および高緯度陸棚・渦力学に対応する（マルチノード GPU 領域分割を要する）。 |

### 海洋鉛直層の増強（`ocean_nz`）
- 海洋鉛直層数 `ocean_nz` を現行の `18層` から `40〜50層`（表層 0–500 m を高密度配置）へ拡張することで、温度躍層（サーモクライン）、赤道潜流（EUC）、海底オーバーフロー、および有光層 BGC の鉛直構造が大きく改善する。
- 結合計算時間の9割以上は大気および埋め込み CRM が占めるため、`ocean_nz` の増強に伴う全体計算コストの増加は数%にとどまり、海洋再現性向上に対する効率が極めて高い。

## 3. マルチ GPU 並列化アーキテクチャ

現行実装は単一 GPU（`cuda` / `mps`）実行であり、`Glevel-5`（`8 × 1` CRM）の長期積分および独立アンサンブル実験（1 GPU × 複数ジョブ並列）に適している。`8 × 8` 3D CRM、`Glevel-6`/`Glevel-7` 長期気候積分、および `1 × 1` 全球雲解像（`Glevel-9`–`11`）への展開に向けて、以下の2段階並列化を想定する。

1. **第1段階：ノード内カラム並列（NVLink 上の `torch.distributed`）**
   - 実行時間の約 85–90% を占めるホスト格子ごとに独立な物理計算（埋め込み CRM・16バンド CKD 放射・2モーメント雲微物理・MYNN 境界層・陸面および植生タイル）をノード内 4–8 GPU へ均等分割し、ホスト SCVT 力学へ集約する。
   - 水平ハロー通信を導入せずに、`Glevel-5` × `8 × 8` 3D CRM や `Glevel-6`–`7` 超パラメータ化気候計算の高速化とメモリ分散を実現する。
2. **第2段階：SCVT 水平領域分割（MPI / NCCL ハロー通信）**
   - SCVT ボロノイ格子を複数ノードへ領域分割し、ホスト力学・FCT 移流・3D OGCM・EVP 海氷に 1-ring / 2-ring ハロー通信を実装する。
   - 単一 GPU メモリ上限（40–80 GB）を超える渦許容・渦解像結合気候（`Glevel-8`–`9`）および `1 × 1` 全球雲解像実験（`Glevel-10`–`11`）を可能にする。

## 4. 拡張候補の地球システム物理過程

基本結合 ESM 構成に対する将来的な拡張候補は以下の通りである。
- **炭素排出駆動モード（`esm-piControl`）**：大気 3D $\mathrm{CO}_2$ 移流と予報型陸海炭素フラックスを完全閉鎖結合し、大気 $\mathrm{CO}_2$ 濃度を予報変数として時間発展させるモード。
- **双方向大気化学**：成層圏・対流圏オゾン光化学（$\mathrm{HO}_x/\mathrm{NO}_x/\mathrm{ClO}_x$・極成層圏雲）、湿地 $\mathrm{CH}_4$ 放出、土壌 $\mathrm{N}_2\mathrm{O}$、および OH ラジカル寿命フィードバック。
- **陸域窒素・リン循環、深層永久凍土、植生デモグラフィ**：$\mathrm{CO}_2$ 肥沃化効果の栄養塩制約を表現する土壌無機態 N/P 循環（$\mathrm{NH}_4^+, \mathrm{NO}_3^-$・生物的窒素固定・溶脱）、深層嫌気分解を伴う永久凍土炭素・メタン動態、および樹高・年齢クラス競争と水ストレス油圧枯死を扱う植生デモグラフィ。
- **モーダル・エアロゾル力学および氷晶核（INP）**：粒径モード別の核生成・凝集・内部混合、黒色炭素（BC）の雪氷上沈着によるアルベド低下、および混合相雲における予報型 INP 結合。
- **高トップ大気および棚氷–海洋相互作用**：QBO や成層圏突然昇温を対象とした高トップ構成（`z_top ~ 80 km`, `70–90` 層）、ならびに棚氷底面融解および氷山カービングの海洋結合。
- **任意の歴史・将来シナリオ外部強制層**：人為起源エアロゾル排出、土地利用変化、火山成層圏エアロゾル光学的厚さ、および太陽スペクトル変動を、マップ不要の普遍物理コアから分離されたプラグイン層として接続する機構。
