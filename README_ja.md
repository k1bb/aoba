# AOBA (Autonomous Optimality Biosphere–Atmosphere)

> **言語 (Language)**: [English (README.md)](README.md) | 日本語

**AOBA** は、生態進化的最適性（EEO: Eco-Evolutionary Optimality）に基づく陸面植生モデルと、超パラメータ化（Superparameterization）全球大気・スラブ海洋を結合した軽量かつ GPU ネイティブな全球気候モデルです。積雲パラメタリゼーション、処方された重力波源分布、および植物機能型（PFT）ごとの経験的パラメータ調整に依存せず、「植物が自律的に決める陸面境界条件」と「大気大循環・偏西風ジェット流路」の双方向結合メカニズムを検証するために設計されています。

## 基本設計思想

1. **積雲と内部重力波の陽な解像（スーパーパラメタリゼーション）**: 全球 T42 スペクトル静力学力学コアの各格子内に、水平周期境界を持つ小型3次元アネラスティック雲解像モデル（`8 × 8` 水平コラム、$\Delta x = \Delta y = 4\ \mathrm{km}$、鉛直50層・上端高度 $z_{\mathrm{top}} \approx 38\ \mathrm{km}$）を埋め込みます。積乱雲の発達、コールドプール、全方位（360°）への対流性重力波の励起・成層圏伝播・砕波、および3次元対流運動量輸送が非静力学方程式から自発的に創発します。
2. **PFT フリーの自律植生境界条件（Pモデル ＋ EEO LAI）**: 陸上の各埋め込み CRM コラム（1ホスト格子あたり64タイル）に対し、葉レベルの純粋 Pモデル（Prentice et al., 2014; Stocker et al., 2020）と EEO 葉面積予測モデル（Cai et al., 2025; Zhou et al., 2025）を1対1で直結します。樹冠の光吸収割合（$\mathrm{fAPAR}$）と葉面積指数（$\mathrm{LAI}$）は、葉の維持・構築コストに基づく光制限と根圏水供給制限の最小値から自律的に決定されます。
3. **変位追従型の実効空力基準面（樹冠突き抜け防止地形処理）**: 大気モデル下端の基準高度（$\tilde{z} = 0$）を裸地標高 $z_{\mathrm{topo}}$ ではなく、ゼロ面変位 $d$ を加えた実効空力基準面 $z_{\mathrm{datum}} = z_{\mathrm{topo}} + d$ に定義します。これにより、実地形上で高木林が発達しても樹冠上端が大気最下層参照高度を突き抜けてモニン・オブコフ相似則が破綻する問題を数学的に回避します。
4. **4バンド解析的2ストリーム放射 ＆ スラブ混合層海洋**: 外部ルックアップテーブル不要の4バンド放射伝達ソルバ（UV/PAR 帯、近赤外帯、水蒸気・CO₂ 吸収帯、波長 8–12 $\mu\mathrm{m}$ 大気の窓領域）と熱力学海氷つきスラブ混合層海洋を組み合わせ、太陽入射と海陸・地形境界のみから気候系を閉じます。
5. **単一コードでの GPU ポータビリティ（`Float32` PyTorch）**: Apple Silicon GPU（`mps` ユニファイドメモリ）上で数年〜数十年のローカル気候積分が動作し、コード変更なしで NVIDIA GPU（`cuda`）へそのままスケールします。

## 出力ファイルと参考文献ディレクトリの保護方針

- **計算出力の分離**: 大容量の NetCDF やチェックポイントによる Google Drive の同期圧迫を防ぐため、シミュレーション出力先はデフォルトで `~/aoba_outputs`（環境変数 `AOBA_OUTPUT_DIR` で変更可）に分離されます。
- **参考文献ディレクトリの保護**: `references/` ディレクトリは `.gitignore`、`.git/info/exclude`、および Git `pre-commit` フックの三重ロックにより、GitHub へは一切アップロードされません（Google Drive 上でのみ自動バックアップされます）。

## 開発ロードマップ

- **Phase 1**: 単一ホストカラム（`B = 1`）での `8 × 8` 3D CRM ＋ 4バンド放射 ＋ サブグリッド Pモデル/EEO-LAI 陸面による放射対流平衡（RCE）テストベッドの構築と検証。
- **Phase 2**: 平滑化実地形を備えた全球 T42 静力学スペクトル力学コアの構築と Held–Suarez ベンチマーク検証。
- **Phase 3**: 実大陸・実地形・スラブ海洋上での全球スーパーパラメタリゼーション結合（`B = 8192`）。
- **Phase 4**: 自律植生フィードバックおよび積雲パラメタリゼーションの歪みを切り分ける要因実験（CO₂ の放射強制力 vs 生理学的強制力の分離実験を含む）。
